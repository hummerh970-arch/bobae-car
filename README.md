# 보배카 (BOBAE CAR)

중고차 매물 링크와 사진으로 YouTube Shorts·Instagram Reels용 세로 영상을 만드는 한국어 웹 앱입니다. CarStudio를 디자인 기준으로 삼아 구성하고, 비교 시트에 적힌 등록 순서와 차량 필드를 반영했습니다.

## 주요 기능

- 매물 링크 입력 후 외부 페이지 열기 및 라벨이 있는 정보 텍스트 붙여넣기
- JPG, PNG, WebP 사진 10~30장 업로드, 썸네일 순서 이동 및 삭제
- 제조사·모델·트림·연식·가격·주행거리·색상·연료·변속기·구동방식·차체·판매자 정보 입력
- 사고·침수·전손·교환·도색·용도·소유자·보증 이력 입력
- 템플릿, 9:16·1:1·16:9, 720p·1080p, 15·25·40초, 자막 스타일 선택
- 브라우저에서 영상 렌더링, 미리보기 및 파일 다운로드
- 배경 음악 트랙 생성, 음량 조절, 음성 파일 포함, 한국어 자막 및 게시 문구 복사
- 작업 중 차량 정보는 브라우저 로컬 저장소에 보관

## 로컬 실행

Node.js가 설치된 컴퓨터에서 저장소 폴더로 이동해 실행합니다.

```powershell
node server.cjs
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 설치할 패키지는 없습니다.

## 영상 만들기

1. 시작 방식을 선택합니다: 매물 링크를 붙여넣어 정보를 불러오거나, 사진을 직접 올리고 차량 정보를 입력합니다. 두 방식 모두 영상에 사용할 사진 10~30장이 필요합니다. JPG/PNG/WebP, 사진당 최대 20MB입니다.
2. 썸네일의 좌우 버튼으로 순서를 맞추고 첫 사진을 대표 사진으로 둡니다.
3. 차량 정보와 이력, 주요 장점, 판매자·연락처를 입력합니다. 모르는 이력은 ‘미확인’으로 둡니다.
4. 스타일·화면 비율·길이·음악·자막을 정하고 필요하면 음성 파일을 올립니다.
5. ‘영상 제작’을 눌러 미리보기하고 다운로드합니다.

사진 수 기준 추천 길이는 10–12장 15초, 13–20장 25초, 21–30장 40초이며 직접 바꿀 수 있습니다. 영상 길이에 따라 제작 시간이 달라집니다. 탭을 닫지 말고 렌더링이 끝날 때까지 기다려 주세요. 인코더가 지원되면 MP4, 그렇지 않으면 WebM으로 저장합니다. 영상은 현재 브라우저에서 만들어지므로 사진이 서버로 업로드되지 않습니다.

## 실제 연결 범위와 한계

- 링크 입력은 외부 매물 페이지를 새 탭으로 열고, 사용자가 복사한 라벨형 텍스트를 입력 폼에 반영합니다. 브라우저 CORS·사이트 접근 차단을 우회하는 크롤러는 이 공개 정적 배포에 포함되어 있지 않습니다. 완전 자동 수집은 해당 사이트 이용 조건을 지키는 별도 서버 API가 필요합니다.
- 한국어 기기 음성 미리듣기는 브라우저의 Speech Synthesis를 사용합니다. 영상에 음성을 넣으려면 음성 파일을 올리거나 별도 TTS API가 연결되어 있어야 합니다. AI TTS는 API 키를 서버 환경 변수로 보관하는 백엔드가 필요합니다.
- SNS 계정 자동 게시 기능은 연결하지 않았습니다. 영상 파일과 게시 문구를 내려받아 직접 게시합니다.
- 브랜드 로고 파일 입력은 편집기의 영상 오버레이 기능에 사용할 수 있습니다.

## 선택적 API 연결

`config.js`에 공개 HTTPS 엔드포인트 주소만 설정할 수 있습니다.

- `listingImportEndpoint`: `POST { url }` 요청을 받고 차량 데이터를 JSON으로 반환하는 백엔드
- `ttsEndpoint`: `POST { text, language: "ko-KR" }` 요청에 MP3 바이트를 반환하고 `GET <endpoint>/status`에 `{ "ready": true }`를 반환하는 백엔드

CORS 허용 출처를 배포 도메인으로 제한하고 요청량과 업로드 크기를 관리하세요. API 키·비밀번호를 GitHub 저장소, Pages 정적 설정, 브라우저 코드에 커밋하지 마세요.
